# Mini Bibliothèque

Mini-site statique de découverte de livres, réalisé en HTML, CSS et JavaScript natif.

## Fonctionnalités
- Accueil avec sélection de livres
- Catalogue de 8 livres
- Recherche par titre, auteur ou catégorie
- Page de détail accessible avec `livre.html?id=...`
- Formulaire de contact avec validation côté navigateur
- Présentation de l'équipe
- Mise en page responsive

## Lancer le projet
Ouvrir `index.html` dans un navigateur. Aucune installation n'est nécessaire.

## Équipe

- Mellak : catalogue, recherche, données, détail et formulaire de contact

## Limitation
Le formulaire est une démonstration front-end : il valide les champs mais n'envoie pas réellement de courriel, car le projet ne possède pas de backend.
